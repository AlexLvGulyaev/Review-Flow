# PROJECT_STATE

## Project Summary

AI-система обработки клиентских обращений с управляемым использованием AI. Реализует Controlled Hybrid pipeline: бизнес-решения фиксируются в базе типовых ситуаций, LLM только адаптирует текст в рамках response_policy, оператор подтверждает решения.

**GitHub:** https://github.com/AlexLvGulyaev/Review-Flow

## Current Status

**Портфельный актив — в продакшн-размещении.** Структура приведена к стандартам AI Automation Portfolio Lab, документация адаптирована. Локальный запуск через `docker compose up --build` подтверждён (Deployment Verification), публичные HTTPS-эндпоинты развёрнуты через центральный Traefik (Deployment Validation).

Применены APL-стандарты публичных демо-ресурсов: **tokenized demo sessions** (защита `POST /api/reviews` демо-сессиями с квотой, rate-limit и IP-лимитом) и **read-only demo RBAC** для ops-консоли (Bearer-токены `administrator`/`operator`/`demo`; роль `demo` — только чтение, мутации enforced на backend). Изменение конфигурации развёртывания требует повторной Deployment Validation в чистом окружении.

**Публичные адреса:**
- Web UI (клиент): https://review-flow.alex-n8n.site
- Контур компании (оператор + администратор): https://review-flow-admin.alex-n8n.site/company
- Backend API: https://review-flow-api.alex-n8n.site/docs

## Commercial Assessment

**Коммерческий потенциал:** Высокий

**Востребованность:** Высокая — автоматизация обработки обращений и квалификация — одна из самых частых задач.

**Основные риски:**
- Логика есть, но отсутствуют интеграции с n8n, Kommo, Bitrix24
- Требуется доработка под конкретные CRM-системы
- Нет готовых интеграций с голосовыми платформами

**Типовые заказчики:**
- Компании с колл-центрами
- Службы поддержки
- Бизнесы с высокой inbound-нагрузкой
